 ~ The Runic Project Scaffolder & Templating Engine ~
===============================================================================

Quick-start your projects by forging new workspaces from reusable templates.

USAGE:
  skapa [OPTIONS]

OPTIONS:
  -n, --name NAME       Name of the project workspace (default: "my-project")
  -c, --creator NAME    Name of the project author (default: "Anonymous")
  -m, --template NAME   Template directory to build from (default: "simple-readme")
  -t, --type TYPE       Project layout: 'o' (open-source) or 'p' (proprietary)
  -l, --license LIC     License identifier for open-source (e.g., MIT, GPL)
  -o, --owner OWNER     Copyright owner for proprietary projects
  -r, --resources DIR   Custom directory path containing templates
  -h, --help            Display this help message and exit

EXAMPLES:
  # Interactive mode (prompts for missing options):
  skapa

  # Quick-forge an open-source project with MIT license:
  skapa -n my-lib -c "Thor" -m simple-readme -t o -l MIT

  # Scaffold a proprietary project:
  skapa --name core-engine --type p --owner "Longhouse Corp"
