*[Released]*

** v0.0.20 (2026-11-24)

A packaging and pipeline release: the program is unchanged, and what the release
rests on is.

*** Continuous integration

- CI loads every module in the checkout instead of building the container image.
  The image's builder stage ends in a =zypper= exit code 4 on the runner and not
  here, so the pipeline cannot rest on it.  Loading =(skapa main)= is the check
  that fails when a file stops compiling; =--help= is answered from a text file
  and never reaches Guile.

*** Packaging

- The Arch recipe unpacks the archive under the name GitHub gives it,
  =skapa-0.0.20=, rather than the name the Codeberg archive used.  As with every
  release, its source checksum is pinned from the published tarball afterwards.

** v0.0.19 (2026-11-24)

A licensing and pipeline release: skapa is MIT, and GitHub builds it.

*** Licensing

- skapa is relicensed under the MIT licence.  =LICENSE= replaces =COPYING=, and
  no file still claims the GNU licences for this project.  The licence bodies
  skapa generates projects with are untouched: =resources/licenses/gpl3= is what
  a generated project asks for, not what skapa itself is under.
- Every source file opens with a =SPDX-License-Identifier: MIT= header, so the
  licence a file is under travels with the file.
- The recipes follow: =guix.scm= and =default.nix= declare MIT, so do the Arch,
  Debian and openSUSE recipes, =resources/help.txt= and the README.

*** Packaging

- The version string is unified at 0.0.19 in =default.nix= and the Arch, Debian
  and openSUSE recipes, which had drifted apart.
- The homepage, the source URLs and the container metadata point at
  =github.com/jjba23/skapa=.
- The Arch recipe installs =LICENSE= instead of =COPYING=.

*** Continuous integration

- GitHub Actions builds the container image, loads the modules and runs the
  launcher on every push to =trunk= and every pull request.
- A =v*= tag publishes a GitHub release whose notes are read out of this file.
- The Woodpecker pipeline is gone; GitHub is the one that runs the build.

Earlier releases, v0.0.1 to v0.0.18, predate this file; their notes are the git
log.
